# Sarkar Signature Studio

Build a premium, interactive e-commerce web experience for a perfume brand called SARKAR, inspired by the attached reference image of the existing Sarkar perfume bottle.

CORE CONCEPT

Create a website called “SARKAR — Create Your Own Perfume” where customers can design their own personalized perfume.

The experience should feel luxurious, dark, sophisticated, masculine, modern, and premium. Think high-end fragrance house + luxury customization studio.

The website should NOT look like a generic Shopify template. It should feel like a premium fragrance brand with strong visual identity.

BRAND IDENTITY

Brand: SARKAR

Visual inspiration:

* Existing Sarkar bottle has a chess-king-inspired silhouette.

* Main bottle colors: deep black and rich royal blue.

* The bottle has a distinctive king chess-piece cap.

* Use black, midnight blue, subtle silver/chrome accents, and white typography.

* Avoid excessive gold.

* Use large cinematic typography and generous whitespace.

* Overall feeling: powerful, mysterious, sophisticated, expensive.

Use the attached Sarkar bottle image as a visual reference for the bottle shape and brand identity.

BRAND STORY

Create a premium storytelling section:

NOT JUST A FRAGRANCE.

A STATEMENT OF PRESENCE.

Explain the idea behind Sarkar:

Sarkar represents authority, individuality, confidence, and presence. The chess-king-inspired bottle represents strategy, power, and the ability to command attention without saying a word.

Keep the writing concise and luxurious.

DESIGN SYSTEM

Typography:

* Use a sophisticated modern serif for major headlines.

* Use a clean sans-serif for body text and UI.

* Large typography.

* Strong contrast.

Colors:

* #050505

* #0B1020

* Midnight blue

* White

* Subtle silver/chrome

Avoid:

* Bright colors

* Cheap gradients

* Cartoon graphics

* Generic SaaS styling

* Excessive rounded cards

* Excessive shadows

* Clutter

RESPONSIVE DESIGN

The website must work beautifully on:

* Desktop

* MacBook

* iPad

* iPhone

* Android phones

On mobile, the perfume builder should become a smooth vertical experience with large touch-friendly controls.

TECHNICAL REQUIREMENTS

Build this as a fully functional React website.

Use reusable components.

Store the perfume customization state so selections persist while navigating between steps.

The final perfume should be generated dynamically from the user’s choices.

Use realistic placeholder product/bottle imagery where necessary, but structure the code so real Sarkar product images can easily be replaced later.

Include polished loading, empty, hover, selected, and error states.

Make the entire experience feel like a real premium fragrance company’s website rather than a student project.

MOST IMPORTANT UX PRINCIPLE

The website should make the customer feel like they are creating something exclusive, not filling out a form.

Every step should feel visual, luxurious, and interactive.

The final experience should communicate:

“You didn’t choose a perfume. You created your SARKAR.”
